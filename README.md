# Codex Computer use｜介紹與操作（互動教學）

線上觀看：https://appjust.github.io/codex-computer-use/

約 7 分鐘的教學動畫，說明 Codex 的 Computer use 怎麼運作（截圖 → 判斷 → 點擊／輸入 → 再確認）、怎麼開啟與安全使用，以及什麼時候該改用指令、外掛／MCP 或內建瀏覽器。

- 三個版本：中文配音＋中英字幕、中文配音＋中越字幕、English narration＋英中字幕
- 章節：起源、原理（循環與權限）、安全邊界、比較、操作步驟、應用示範、展望與回顧
- 互動練習：這個任務該用哪一種工具？

資料依 OpenAI 官方文件（learn.chatgpt.com/docs：computer-use、browser、changelog），查核日 2026-10-09；示範案例為自行設計的情境。功能與介面可能已更新，請以官方文件為準。

本機觀看：在此資料夾執行 `python -m http.server 8000`，開啟 http://localhost:8000/
